# Football Analytics Portfolio

## Project 1: Match Outcome Predictor
Logistic regression model trained on 9,000+ international matches (2012-2021) to predict FIFA World Cup match outcomes. Uses custom Elo ratings, rolling form features, and home advantage encoding.
**Stack:** Python, Pandas, Scikit-learn, Seaborn

## Project 2: Expected Goals (xG) Model (In Progress)
Gradient boosting model trained on 21,000+ shots from La Liga (StatsBomb open data) to predict shot-to-goal probability. Includes pitch dashboard showing scoring probability zones.
**Stack:** Python, Pandas, XGBoost, Matplotlib, Seaborn
